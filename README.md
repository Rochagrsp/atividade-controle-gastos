# Controle de Gastos com SQL

Projeto desenvolvido para praticar consultas SQL utilizando **MySQL** e **MySQL Workbench**.

## Tecnologias
- MySQL
- SQL
- MySQL Workbench

## Funcionalidades
- Consulta e contagem de gastos.
- Identificação de compras por impulso.
- Consulta de despesas parceladas.
- Identificação dos maiores gastos.
- Consulta por cartão utilizado.

## Objetivo
Praticar criação de bancos de dados, tabelas, filtros e ordenação de dados como parte dos estudos em Desenvolvimento de Sistemas.
